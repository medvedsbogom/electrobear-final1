# ЭлектроМишка — альтернативный снимок прототипа
Небольшой backend на Python / FastAPI с методом `POST /ask` и интеграцией GigaChat.

Основное описание проекта и инструкция: [electrobear-backend](https://github.com/medvedsbogom/electrobear-backend).

Это отдельный снимок той же идеи, а не самостоятельный кейс портфолио. Перед запуском установите зависимости из `requirements.txt` и задайте переменную окружения `GIGACHAT_AUTH_KEY`. Команда: `uvicorn main:app --reload`.

Ранее попавший в Git ключ нужно перевыпустить. Текущая версия остаётся прототипом без пользовательской авторизации и ограничения запросов.
